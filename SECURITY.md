# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's **Report a vulnerability**
button in the repository Security tab so the report can be handled privately.

## Safe-use note

This project analyzes URL text only and intentionally makes no network requests. Do not visit a
suspicious URL to test whether the result is correct. A LOW score is not a guarantee that a URL is
safe; combine this tool with browser protections, reputation services, and human review.
